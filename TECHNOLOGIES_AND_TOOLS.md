# Technologies and Tools Used

## Software & Development Tools
- Visual Studio Code
- PlatformIO
- Wokwi Simulator
- Git
- GitHub

## Programming Language
- C++ (Arduino)

## Hardware Components
- Arduino Uno
- Potentiometer
- L298N Motor Driver
- DC Motor
- Red LED
- Green LED
- 220Ω Resistors
- Mini Breadboard

## Arduino Concepts Used
- `analogRead()`
- `analogWrite()`
- PWM (Pulse Width Modulation)
- `pinMode()`
- `digitalWrite()`
- Serial Monitor
- Analog input
- Digital output

## Arduino Pin Usage

| Pin | Purpose |
|---|---|
| A0 | Potentiometer input |
| D5 | Red LED |
| D6 | Green LED |
| D7 | L298N IN2 |
| D8 | L298N IN1 |
| D9 | L298N ENA / PWM |
